Pocket Assistant

A free voice and text assistant with a female voice that speaks with emotion. Notes, tasks and timers stay in this browser. The page has no server, account or tracking.

Hands-free is off.

Hands-free keeps the microphone on. Chrome sends what it hears to Google's speech service to turn it into text, so switch it off when you want full privacy. Typing never leaves the phone.

      Make it a real Android assistant

      1
      Install it like an app. Host this file on an https address (GitHub Pages or Netlify Drop), open it in Chrome on your phone, allow the microphone once, then choose menu, Add to Home screen. Chrome then remembers the permission.
      2
      Hands-free needs one tap. Browsers do not let a page switch on the microphone with no touch at all. The page tries to start by itself, and if Chrome refuses it, one tap anywhere starts continuous listening. Keep the screen on and the tab open.
      3
      About the emotions. The voice is your phone's built-in text-to-speech. Emotion comes from changing pitch, speed and volume, so it is expressive but not a human actor. Pick another voice in the Voice list if one sounds better on your phone.
      4
      Go native for the Siri parts. A web page cannot run in the background, open other apps, place calls, send texts or set system alarms. A free Android Studio project with SpeechRecognizer, TextToSpeech and Android intents can, and an offline engine such as Vosk keeps audio on the device.

      This assistant matches phrases you give it; it is not a language model.
